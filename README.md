# ❤️ Heart Disease Prediction App

An interactive web app that predicts the likelihood of heart disease using multiple ML algorithms:
- Logistic Regression
- Random Forest
- SVM
- KNN

### 🚀 Features
- User-friendly Streamlit interface
- Shows accuracy and recall metrics for all models
- Educational chatbot for heart health information
- Visual data insights (charts, pie graphs)
- Safe input and preprocessing pipeline

### 🧠 Tech Stack
- Python, Streamlit, Scikit-learn, Pandas, NumPy, Matplotlib, RapidFuzz

### 📊 Evaluation
| Model | Accuracy (%) | Recall (Macro %) |
|--------|---------------|------------------|
| Random Forest | 90.45 | 88.75 |
| Logistic Regression | 82.35 | 80.12 |
| SVM | 84.60 | 81.22 |
| KNN | 86.13 | 84.00 |
